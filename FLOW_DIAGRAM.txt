                    BATCH PREPROCESSING & CACHING FLOW
════════════════════════════════════════════════════════════════════════════════

┌──────────────────────────────────────────────────────────────────────────────┐
│                           ADMIN SETUP (FIRST TIME)                           │
└──────────────────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────┐
    │ POST /api/v1/vectorize-all-papers?batch_size=100               │
    │ (Takes 8-10 minutes for 5000 papers)                           │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ PaperRepository.get_total_papers_count() → 5000                │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ Loop Batches (Batch Size = 100)                                │
    │                                                                  │
    │ ┌────────────────────────────────────────────────────────────┐ │
    │ │ Batch 1 (Papers 1-100)                                     │ │
    │ │  ├─ get_abstracts_batch(offset=0, batch_size=100)         │ │
    │ │  ├─ Preprocess abstracts (tokenize, stem, remove stopwords)│ │
    │ │  ├─ Compute TF-IDF vectors                                │ │
    │ │  └─ Add to all_tfidf_vectors list                         │ │
    │ └────────────────────────────────────────────────────────────┘ │
    │                          ↓ (repeat)                             │
    │ ┌────────────────────────────────────────────────────────────┐ │
    │ │ Batch 2 (Papers 101-200)                                   │ │
    │ │  └─ Same process...                                        │ │
    │ └────────────────────────────────────────────────────────────┘ │
    │                          ↓ (... repeat 50 times ...)            │
    │ ┌────────────────────────────────────────────────────────────┐ │
    │ │ Batch 50 (Papers 4901-5000)                                │ │
    │ │  └─ Same process...                                        │ │
    │ └────────────────────────────────────────────────────────────┘ │
    │                                                                  │
    │ Result after all batches:                                       │
    │  • all_datas[] = [5000 papers with id, title, abstract]        │
    │  • all_tfidf_vectors[] = [5000 TF-IDF vectors]                 │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ Compute Cosine Similarity Matrix (O(n²))                        │
    │                                                                  │
    │ cosine_matrix[i][j] = similarity(vector_i, vector_j)           │
    │                                                                  │
    │ For 5000 papers: 5000 × 5000 = 25,000,000 comparisons         │
    │ ├─ Progress 10%: 2,500,000 done                               │
    │ ├─ Progress 20%: 5,000,000 done                               │
    │ ├─ ...                                                          │
    │ └─ Progress 100%: Complete! Matrix ready                      │
    │                                                                  │
    │ Result: cosine_matrix[][] (5000x5000)                         │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ VectorizationCacheService.save_precomputed_vectors()            │
    │                                                                  │
    │ Serialize to disk:                                              │
    │ {                                                               │
    │   "datas": [...5000 papers...],                                │
    │   "tfidf_vectors": [...5000 vectors...],                       │
    │   "cosine_matrix": [...5000x5000 matrix...]                    │
    │ }                                                               │
    │                                                                  │
    │ Save as: app/cache/vectorization/precomputed_vectors.pkl       │
    │ (Binary pickle format, ~250MB)                                 │
    │                                                                  │
    │ Metadata: app/cache/vectorization/metadata.json                │
    │ {                                                               │
    │   "total_papers": 5000,                                        │
    │   "matrix_size": 5000,                                         │
    │   "saved_at": "2024-05-17T10:30:45.123456",                   │
    │   "cache_file": "app/cache/vectorization/precomputed_vectors"  │
    │ }                                                               │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ ✅ Cache Ready! Setup Complete                                 │
    │    Now all recommendations will use cached vectors!            │
    └─────────────────────────────────────────────────────────────────┘

                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ RecommendationService.__init__(repo, auto_build=True)          │
    │                                                                  │
    │ Constructor flow:                                               │
    │  1. Initialize with paper_repository                           │
    │  2. Create VectorizationCacheService instance                  │
    │  3. auto_build=True → Call _build_model_with_cache()           │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ _build_model_with_cache()                                       │
    │                                                                  │
    │ ┌──────────────────────────────────────────────────────────┐   │
    │ │ IF cache.is_cache_valid():                               │   │
    │ │   ↓                                                       │   │
    │ │   Load from disk (VectorizationCacheService.load())      │   │
    │ │   ├─ Open pickle file                                    │   │
    │ │   ├─ Deserialize binary data                            │   │
    │ │   ├─ Set self.datas = datas                            │   │
    │ │   └─ Set self.cosine_sim_matrix = matrix                │   │
    │ │   ✅ DONE in 50ms!                                       │   │
    │ │                                                           │   │
    │ └──────────────────────────────────────────────────────────┘   │
    │ ELSE:                                                           │
    │   ├─ Build default model (100 papers, 3s)                     │
    │   └─ No cache needed                                          │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ get_recommendations_by_paper_id(paper_id=123, top_n=5)          │
    │                                                                  │
    │ ├─ Find paper index in self.datas                              │
    │ ├─ Get similarity scores from self.cosine_sim_matrix[index]    │
    │ ├─ Sort scores (descending)                                    │
    │ └─ Return top 5 recommendations                                │
    │                                                                  │
    │ Time: ~100ms                                                    │
    └──────────────────────────┬──────────────────────────────────────┘
                               ↓
    ┌─────────────────────────────────────────────────────────────────┐
    │ Return Response                                                 │
    │ {                                                               │
    │   "status": "success",                                         │
    │   "recommendations": [                                         │
    │     {"id": 456, "title": "...", "similarity_score": 0.85},    │
    │     {"id": 789, "title": "...", "similarity_score": 0.82},    │
    │     ...                                                         │
    │   ]                                                             │
    │ }                                                               │
    │                                                                  │
    │ Total time: ~150ms                                             │
    │ (vs 3100ms without cache!)                                     │
    └─────────────────────────────────────────────────────────────────┘

    ┌─────────────────────────────────────────────────────────────────┐
    │ ✅ Request Complete!                                           │
    │    Next requests will also use the same cached data            │
    │    (No more preprocessing or vectorization needed!)            │
    └─────────────────────────────────────────────────────────────────┘

                         MEMORY EFFICIENCY

Batch Processing (Memory Efficient):
    Process Papers 1-100:
      • Load 100 abstracts into memory
      • Process TF-IDF
      • Store results
      • CLEAR FROM MEMORY ✓
      Memory peak: ~10MB
         ↓
    Process Papers 101-200:
      • Load next 100 abstracts into memory
      • Process TF-IDF
      • Store results
      • CLEAR FROM MEMORY ✓
      Memory peak: ~10MB
         ↓
    ... (repeat 50 times) ...
         ↓
    Total memory used: CONSTANT ~10-50MB per batch
    (NOT 500MB for all 5000 papers at once!)

All-At-Once Processing (Memory Inefficient - AVOIDED):
    Load ALL 5000 papers into memory:
      Memory peak: ~500MB (or crash!)


════════════════════════════════════════════════════════════════════════════════

                           DISK STORAGE

Cache Directory Structure:
    app/
    └─ cache/
       └─ vectorization/
          ├─ precomputed_vectors.pkl    ← Binary cache (250MB for 5000)
          └─ metadata.json              ← Metadata (< 1KB)

Binary Pickle Format Benefits:
    ✓ Fast serialization/deserialization (50ms load time)
    ✓ Preserves Python objects exactly
    ✓ Efficient storage (compared to JSON)
    ✓ No additional dependencies

Cache Reusability:
    • Generated ONCE, used MANY TIMES
    • Survives application restarts
    • Can be archived, backed up
    • Can be versioned by paper count
